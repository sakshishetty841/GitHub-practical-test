# Sakshi Shetty — Personal Developer Portfolio

A responsive two-page personal developer portfolio website built using semantic HTML5, CSS3, and vanilla JavaScript.

## Website Structure
- Page 1: Home (`index.html`) — Hero section, About Me, Technical Skills, and Introduction.
- Page 2: My Work (`work.html`) — Featured Projects, Achievements, Certifications, Extracurricular Experience, and Contact.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Playfair Display, DM Sans)

## Project Structure
```
portfolio/
├── index.html
├── work.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   ├── icons/
│   └── resume.pdf
└── README.md
```

## How to Run Locally
Run a local static server from the project directory:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in any web browser.
