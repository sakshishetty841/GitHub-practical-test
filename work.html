NetraDrishti — Explainable AI for Diabetic Retinopathy Triage in Rural India

An AI-powered healthcare solution designed to support early diabetic retinopathy screening and referral workflows, particularly in rural healthcare settings. Built around ASHA worker, doctor and administrator dashboards.

  • Patient registration and retinal image upload workflows
  • Backend built using Node.js and Express.js with Prisma ORM
  • SQLite local development with PostgreSQL-compatible production configuration
  • JWT authentication, bcrypt password hashing and Multer file upload handling
  • Axios integration connecting to an explainable AI service

Glowing Lily — Interactive Hand-Tracking Experience

An interactive creative coding experiment where a digital lily responds to hand movements in real time through ordinary webcam video feeds.

  • Real-time hand and index finger tracking using Google MediaPipe
  • Live camera stream analysis and processing with OpenCV in Python
  • Interactive flower movement and petal blooming kinetics with Pygame
  • Fluid human-computer interaction without specialized hardware
